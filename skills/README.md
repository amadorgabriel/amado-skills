| Bucket | Descrição | Vai no plugin? |
| --- | --- | --- |
| [portfolio](./portfolio/) | Carreira, currículo, cartas e portfólio (autorais promovidas) | Sim |
| [in-progress](./in-progress/) | Rascunhos autorais em validação local | Não |
