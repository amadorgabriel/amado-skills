# education

Skills para explicar e estudar conceitos técnicos com material visual.

- [`lesson`](./lesson/): gera uma aula HTML autocontida (`./lessons/<slug>/lesson.html`) com mapa conceitual, progressão do problema real até o termo técnico, glossário, quiz e fontes primárias. Adaptada de [YudiG12/ganeko-skills](https://github.com/YudiG12/ganeko-skills) (`skills/beta/lesson/`, licença MIT em `lesson/LICENSE`).
