# Documentação

As skills de agente **não** ficam nesta pasta. A fonte (o `SKILL.md` que o agente executa) vive em `skills/`. Aqui está a documentação humana do repositório e das skills já promovidas.

## Onde está cada coisa

- **Fonte da skill:** `skills/<bucket>/.../SKILL.md`
  - Promovidas (na vitrine e no plugin): `skills/portfolio/<skill>/`
  - Rascunhos em validação: `skills/in-progress/<skill>/`
  - Skills de terceiros: `skills/external/<autor>/<skill>/`
- **Docs humanas:** `docs/<categoria>/<skill>.md`
  - Existem **somente** para skills promovidas. Hoje isso é só [docs/portfolio/](./portfolio/).
  - Skills em `external/` e `in-progress/` **não** têm página em `docs/` até graduarem para uma categoria estável (veja o checklist em [writing-skills.md](./writing-skills.md)).
- **ADRs:** [docs/adr/](./adr/) registra decisões de estrutura e instalação.
